# LernBot 7.0 – Phase 3.8

Eigenständige Forschungsphase mit statistischer Hypothesenprüfung, Messrauschen und 90 Experimenten pro Strategie.

## Installation

Alle vier Webdateien `index.html`, `main.js`, `model.js`, `style.css` in `Mein-lernbot/evolution/phase38/` ablegen. Danach GitHub Pages unter `/Mein-lernbot/evolution/phase38/` öffnen.

## Test

Seed 2027, Messrauschen Normal, Strategie Statistische Prüfung, Welt kann sich ändern. Start bis 90/90. Anschließend 24 Welten vergleichen. Mit anderen Seeds und Rauschstufen wiederholen.

## Grenzen

Die Simulation ist künstlich und deterministisch. Es handelt sich um feste Algorithmen, nicht um eine autonome allgemeine KI. Der Modellfehler wird gegen die verborgene Wahrheit ausgewertet. Hypothesen sind Hinweise, keine Beweise.
