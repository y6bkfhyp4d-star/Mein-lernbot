## Was ist neu?
Phase 4.3 verlangt bei auffälligen Messungen zwei oder bei starkem Rauschen drei passende Beobachtungen, bevor sie einen Alarm auslöst. Sie schätzt Rauschen aus Messungen und kann ihre Strategie im Verlauf anpassen. Drei verschiedene Seeds liefern insgesamt 108 unbekannte Testwelten. Verglichen werden Evolution 4.1, Anpassungsfähigkeit 4.2 und Selbstkorrektur 4.3.

Die Tests sind eine deterministische Simulation. Keine echte KI und keine automatische Änderung des Quellcodes. Weniger Fehlalarme können mit weniger erkannten Veränderungen einhergehen.
