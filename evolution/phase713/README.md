# LernBot Phase 7.13 – Abschluss von Phase 7

## Ziel
Die bereits vorhandene Wissens-Recherche-Pipeline technisch abschließen, Fehlerdiagnostik nachvollziehbar testen und offene Grenzen ehrlich dokumentieren. Diese Phase macht keinen Wahrheitsgarantie- oder AGI-Anspruch.

## Installation auf GitHub (iPhone)
1. Im Ordner `evolution` Datei `phase713/README.md` erstellen und committen.
2. **Alle Dateien aus `evolution/phase713/`** in den Ordner `evolution/phase713/` hochladen (keinen weiteren `phase713` Unterordner).
3. Im vorhandenen `.github/workflows/` nur die Datei `lernbot-phase713.yml` anlegen. Code siehe mitgelieferte Workflow-Datei oder Chat.
4. GitHub Actions `LernBot 7.0 - Phase 7 Abschlusspruefung 7.13` starten.
5. Seite `https://y6bkfhyp4d-star.github.io/Mein-lernbot/evolution/phase713/` aufrufen, oben `Wissen laden & prüfen`, dann `Ergebnisse kopieren` drücken.

## Wichtige Grenzen
- Echte Aussagen aus dem Phase-7.11-Bericht werden nur geprüft und nie überschrieben.
- Der synthetische Prüfkatalog enthält auch bewusst falsche Beispiele. Diese werden niemals in die Wissensdatenbank übernommen.
- Der Abschlussstatus bedeutet **technisch abgeschlossen**, nicht unabhängig sachlich bestätigt.
- Syntaktisch korrekte, inhaltlich falsche Aussagen bleiben möglicherweise unentdeckt.
- Die Kalibrierung passt nur den Mindestlängen-Parameter an Trainingsbeispiele an, **keine autonome semantische Fehlerkorrektur**.
- Andere, bereits existierende Versionen bleiben im Repository unverändert.
