# LernBot 7.0 – Phase 3.2

Eigenständiges Labor für verlässliche Lernmessung.

## Start

Alle fünf Dateien direkt nach `evolution/phase32/` hochladen. Dann `https://y6bkfhyp4d-star.github.io/Mein-lernbot/evolution/phase32/` öffnen.

## Tests

- Neugier und Zufall untersuchen 15 Material-Aktions-Kombinationen.
- Beide Strategien bekommen in jeder Welt dieselben 15 Testfälle.
- Fehlende Vorhersagen werden mit dem Basiswert 0 °C bewertet, nicht ignoriert.
- Der Indikator „Sicherheit“ ist eine Stichprobenheuristik und keine kalibrierte Wahrscheinlichkeit.
- Trainings- und Testwelten besitzen bewusst unterschiedliche Materialparameter. Dies ist ein harter Transfer-Test; auswendig gelernte Materialwerte können dabei scheitern.
- Die simulierten Materialgesetze sind stark vereinfacht. Der Agent lernt keine allgemeine KI und verändert keinen eigenen Programmcode.

Die vorherigen Phasen und LernBot 6.0 bleiben unverändert. Speicherung nur unter `lernbot7.phase32.v1`.
